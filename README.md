# Batumi Job Radar

Telegram-based radar for tracking fresh job opportunities in Batumi, with a focus on SMM, marketing, content creation, and digital roles.

## Overview

The project was created to automate the search for relevant job opportunities and reduce the time spent manually checking multiple sources.

## Sources

The radar monitors public sources such as:

- Telegram channels and groups
- Threads
- Job boards
- Local vacancy communities

## Features

- Fresh vacancy monitoring
- Filtering by location
- Focus on Batumi-based opportunities
- SMM and marketing vacancy detection
- Telegram notifications
- Compact vacancy cards
- Direct links to original posts

## Purpose

The goal of the project is to collect relevant vacancies from multiple sources and deliver them in one place for faster review.
